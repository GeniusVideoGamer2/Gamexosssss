# GameXOSTR

Original OS scaffold with boot, installer, desktop, apps and services modules.

This is the extracted scaffold from the bundled `Gamexosssss-Eben.zip` archive.

## Layout

- `boot/` bootloader configuration
- `installer/` installer and partition selector
- `desktop/` desktop shell
- `ui/` rendering and liquid glass visuals
- `dock/` dock implementation
- `apps/` user-facing apps
- `services/` background services
- `kernel/` kernel entry and core
- `themes/` theme configuration
- `live-build/` Debian live ISO build configuration

## Build

```bash
make
```
