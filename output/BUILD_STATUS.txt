GameXOSTR ISO build status
==========================

Current build status:
- The previous GitHub Actions run reported success only because the workflow uploaded a 1 KB zero-filled placeholder. That workflow behavior has now been removed.
- The firmware index failure was fixed by disabling the old helper and explicitly requesting common firmware packages.
- The next run reached ISO packaging, then failed because Ubuntu's old Syslinux template expects `/usr/lib/syslinux/isolinux.bin` and `/usr/lib/syslinux/vesamenu.c32`, while Debian Bookworm installs those files under different paths.
- The live-build config now selects GRUB2 for the hybrid ISO to bypass the incompatible legacy Syslinux template.
- The workflow now requires a real ISO larger than 100 MB with an El Torito boot catalog before upload.
- The GRUB2 configuration change still needs a successful GitHub Actions run before a real ISO can be claimed or downloaded.

The only way to produce the ISO in a valid environment is to run this on a real Debian 12 / Ubuntu 24.04 host or a privileged VM/container:

sudo apt-get update
sudo apt-get install -y live-build debootstrap debian-archive-keyring squashfs-tools xorriso grub-pc-bin grub-efi-amd64-bin mtools
sudo bash build.sh

Expected output:
- GameXOSTR.iso in the repository root

This directory is reserved for the verified ISO artifact. No bootable ISO is present yet.
